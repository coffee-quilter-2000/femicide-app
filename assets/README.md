# assets/: images for the app

OWNER: Person 5 · branch: content

- **Banner (photo collage):** save as `banner.jpg` in this folder. The app picks it up automatically.
  - Wide image, about **2400 × 600 pixels**. The banner is cropped to fit the window, so keep faces away from the top and bottom edges.
  - Keep it under about **1 MB** (export as JPEG, quality ~80) so the page loads quickly.
  - A dark overlay is added on top so the white title stays readable.
- **Credit every photo** in `content/sources.md`, and use photos only with permission from their source.
- Describe the collage for screen readers in `banner_alt` in `content/header.toml`.
